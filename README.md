# Theatro v 0.1

Motor de juegos 3D minimalista inspirado en Bitsy y Pilas Engine, programado en JavaScript, basado en Three.js y diseñado con fines educativos mediante una metáfora teatral.
## Características

- La escena 3D se construye con vóxeles pero se permite la importación de modelos 3D en formato glb o gltf
- API completamente en español
- Basado en ThreeJS, por eso el nombre del motor
- Enfoque educativo
- Metáfora teatral para la construcción de juegos
- Código ligero y fácil de leer
- Ideal para enseñanza y prototipos

## Instalación

1. Descarga las carpetas `dist` y `assets`.
2. Instala las dependencias necesarias.
3. Importa el motor:

```js
import {
  Actor,
  Escena,
  Tramoyista,
  Director,
  Protagonista
} from "./dist/theatro.esm.js";
```
